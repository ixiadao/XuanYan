# 解析与生成 JSON 文本

`packages/json` 是普通玄言本地包，提供严格完整文本解析与生成：

- `解析JSON文本(借用<字符串>) -> 结果<列表<字符串>, 字符串>`
- `生成JSON文本(列表<字符串>) -> 结果<字符串, 字符串>`
- `JSON项类型(借用<字符串>) -> 结果<字符串, 字符串>`
- `JSON项文本(借用<字符串>) -> 结果<字符串, 字符串>`
- `JSON创建空值项() -> 字符串`
- `JSON创建布尔项(布尔) -> 字符串`
- `JSON创建数字项(字符串) -> 结果<字符串, 字符串>`
- `JSON创建字符串项(字符串) -> 字符串`
- `JSON创建数组开始项() -> 字符串`
- `JSON创建数组结束项() -> 字符串`
- `JSON创建对象开始项() -> 字符串`
- `JSON创建对象成员项(字符串) -> 字符串`
- `JSON创建对象结束项() -> 字符串`

解析结果是保持原顺序和层级的事件列表。`JSON项类型` 返回 `空值`、`布尔值`、
`数字值`、`字符串值`、`数组开始`、`数组结束`、`对象开始`、`对象成员` 或
`对象结束`。`JSON项文本` 返回布尔值和数字的文本、解码后的字符串或对象成员名；
空值和容器边界返回空文本。调用方不应直接解释列表项的包内编码。

生成器消费同一种事件列表。动态构造 JSON 时应使用 `JSON创建...项` 函数；数字
构造函数只接受严格 JSON 十进制文本。字符串和对象成员名会转义引号、反斜杠与
控制字符，其他有效 UTF-8 文本保持原样。

在项目的 `xuan.toml` 中声明本地依赖：

```toml
[dependencies]
std = { path = "../xuanyan/stdlib" }
json = { path = "../xuanyan/packages/json" }
```

然后导入公开函数：

```xy
导入 json::JSON项文本;
导入 json::JSON项类型;
导入 json::生成JSON文本;
导入 json::解析JSON文本;
```

解析器接受空值、布尔值、十进制数字、字符串、数组和对象，解码 JSON 转义与
Unicode 代理对。数字保留输入中的原始十进制文本。

边界：

- 输入必须是有效 UTF-8，且不超过 1048576 个字节。
- 嵌套不得超过 128 层。
- 解析结果和生成输入不得超过 4096 项。
- 生成结果不得超过 1048576 个 UTF-8 字节。
- 只接受一个完整严格 JSON 值，拒绝尾随内容。
- 不提供结构体或枚举自动序列化、流式或增量接口、JSON5、Schema、DOM 或随机访问树。
