# 玄言 v0.1.6 技术预览

发布日期：2026-08-01

v0.1.6 是一次编译诊断、编辑器接入和发布闭环修复，不扩展 v0.1 的语言与标准库
边界。

## 本轮变化

- 结构体临时值的资源字段移动在进入 MIR 前统一报告 `SEM031`，不再落入原生后端
  的 `INT001` 内部错误。
- 首次随正式 Release 提供 VS Code 基础扩展，支持 `.xy` 文件识别、语法高亮和
  启动已有 `xuanyan-lsp`。
- VS Code 扩展支持受限工作区，并关闭玄言文件中中文字符的非 ASCII 警示框。
- VSIX 与 Windows、Linux 工具链归档一起接受敏感内容扫描、SHA-256 校验和
  Ed25519 签名清单约束。

工具链归档只包含预编译 CLI、LSP、公开玄言源码、示例、文档和第三方许可。VSIX
只包含采用 MIT 许可的编辑器客户端，不包含编译器或语言服务器的 Rust 实现源码。

## 当前边界

v0.1.6 仍是 x86_64 Windows 与 Linux 技术预览，不包含安装器、操作系统信任链
代码签名、自动更新、远程包仓库、完整 HTTP 客户端、异步运行时、HTTP/2、HTTP/3
或用户 FFI。核心编译器和语言服务器源码继续保留在私有仓库。
