# 玄言 v0.1.2 技术预览

这是面向 x86_64 Windows 与 Linux 的原生命令行、阻塞式 HTTP/1.1 和桌面网页应用
技术预览。

发布包包含预编译的 `xuanyan` CLI、`xuanyan-lsp`、完整 `stdlib` 和可复用的
`packages/http`。用户解压后即可检查、运行、构建和测试玄言程序，不需要安装
Rust、Cargo 或 rustc。

本版本新增：

- 阻塞式原生顶层窗口、确认框和桌面网页窗口。窗口支持系统移动、缩放、最小化、
  最大化和关闭。
- 使用 HTTP 包和桌面网页窗口组成的单进程桌面 Web 应用，窗口关闭后确定性停止并
  回收监听线程。
- HTTP/1.1 分块请求正文、连接空闲超时、监听停止与原生 TCP 就绪等待。
- Windows 与 WSL2/Linux 免 Rust 发布目录中的 CLI、LSP、标准库、HTTP 包和原生产物
  门禁。

下载与平台对应的归档，并使用同名 `.sha256` 文件校验：

- `xuanyan-v0.1.2-windows-x86_64.zip`
- `xuanyan-v0.1.2-linux-x86_64.tar.gz`

Windows 桌面网页窗口需要系统 WebView2 Runtime；Linux 桌面窗口需要 GTK3，桌面
网页窗口还需要 WebKitGTK 4.1。这些是桌面运行库，不是玄言编译对 Rust 的依赖。

当前不包含异步运行时、HTTP/2、HTTP/3、TLS、用户 FFI、安装器、自动更新、代码签名
或完整 macOS 承诺。未覆盖的原生语言组合继续报告 `NBE001`，不会回退到 Rust 后端、
解释器或第二编译管线。
