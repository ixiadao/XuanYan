# 玄言 v0.1.1 技术预览

这是面向 x86_64 Windows 与 Linux 的阻塞式 HTTP/1.1 Web 应用技术预览。

发布包包含预编译的 `xuanyan` CLI、`xuanyan-lsp`、完整 `stdlib` 和可复用的
`packages/http`。用户解压后即可检查、运行、构建和测试使用 HTTP 包的玄言程序，
不需要安装 Rust、Cargo 或 rustc。

本版本新增：

- 有界 HTTP/1.1 请求解析，支持 GET、HEAD、POST、`Content-Length` 请求体和持久连接。
- 稳定的 400、404、405、413、431、500、501 响应与精确响应长度。
- 复用 HTTP 包的静态文件服务器和可直接在浏览器使用的状态、回声应用。
- Windows 与 Linux 免 Rust 发布目录中的 HTTP 包导入和原生产物门禁。

下载与平台对应的归档，并使用同名 `.sha256` 文件校验：

- `xuanyan-v0.1.1-windows-x86_64.zip`
- `xuanyan-v0.1.1-linux-x86_64.tar.gz`

当前不包含异步运行时、HTTP/2、HTTP/3、TLS、用户 FFI、安装器、自动更新、代码签名
或完整 macOS 承诺。未覆盖的原生语言组合继续报告 `NBE001`，不会回退到 Rust 后端、
解释器或第二编译管线。
