# 玄言 v0.2.0 技术预览

发布日期：2026-08-03

v0.2.0 在既有 Windows/Linux 独立原生工具链上形成 Android 与 HarmonyOS NEXT
移动技术预览。四个平台继续复用唯一 Compiler、HIR、MIR 和原生代码生成管线。

## 本轮变化

- `构建` 新增 `android-arm64-v8a` 与 `harmonyos-next-arm64-v8a` 两个固定平台
  选择，直接生成 AArch64 ELF 共享库，不引入任意 target triple 或第二编译管线。
- Android 与 HarmonyOS NEXT 使用私有平台壳装入同一共享边界；官方 JNI、
  ArkTS/UIAbility、Node-API 和移动宿主适配源码不公开。
- 两个平台覆盖 UTF-8 文本与结果、应用沙箱文件、有界 HTTPS、JSON、单调计时、
  等待和前后台停止边界。
- Windows 与 Linux 继续提供完整 CLI、LSP、标准库、普通玄言包、示例和离线安装。

工具链归档只包含预编译 CLI、LSP、公开玄言源码、示例、文档、安装脚本和第三方
许可。VSIX 只包含采用 MIT 许可的编辑器客户端。编译器与语言服务器的 Rust 实现、
Cargo 工作区、PDB、私钥和服务器配置不进入发布资产。

移动端不发布通用或商店签名 APK/HAP，也不公开官方 JNI、Node-API 和移动宿主
适配源码。Windows/Linux 工具链负责生成 `libxuanyan.so`；私有平台壳继续使用
官方 SDK、签名配置和设备完成 arm64-v8a 真机验收。

## 当前边界

v0.2.0 不包含 macOS/iOS 发布支持、远程包仓库、调试器、异步运行时、任意移动
目标描述、用户 FFI、完整原生控件框架或跨平台 UI 框架。技术预览不承诺旧语法、
旧包格式、旧诊断或旧公共 API 兼容。
