# 玄言 v0.1.0 技术预览

这是面向 x86_64 Windows 与 Linux 的首个可下载技术预览。

发布包包含预编译的 `xuanyan` CLI、`xuanyan-lsp` 和完整 `stdlib`。用户解压后即可
执行检查、运行、构建、测试、格式化和 LSP 工作流，不需要安装 Rust、Cargo 或
rustc。运行、构建和测试只使用玄言的 MIR 与独立原生代码生成器。

下载与平台对应的归档，并使用同名 `.sha256` 文件校验：

- `xuanyan-v0.1.0-windows-x86_64.zip`
- `xuanyan-v0.1.0-linux-x86_64.tar.gz`

当前只支持本地路径包；不包含安装器、自动更新、代码签名、远程包仓库或完整 macOS
承诺。原生后端尚未覆盖的语言组合会报告 `NBE001`，不会回退到 Rust 后端、解释器
或第二编译管线。
