# 玄言 v0.1.3 技术预览

这是面向 x86_64 Windows 与 Linux 的闭源官方编译器公开技术预览。编译器与语言
服务器以预编译二进制发布，标准库、HTTP 包和可直接运行的 `.xy` 示例以可见玄言
源码随包提供；使用玄言不需要安装 Rust、Cargo、rustc，也不需要账户、远程激活或
远程包仓库。

本版本新增：

- 原生产物使用唯一临时文件和安全替换，失败时保留原有可执行文件。
- v0.1 规范接受程序在 Windows/Linux 中持续经过真实原生构建、执行、释放和失败
  出口契约验证。
- 明确用户继续拥有自己的源码，并可免费使用、分发、出售和商业化玄言生成程序。
- 发布归档随附许可、快速入门、语言参考、已知限制、反馈指南、安全报告说明和
  可直接运行的 `.xy` 示例。
- 公开分发仓库使用结构化缺陷与建议表单，不接收编译器源码拉取请求。

下载与平台对应的归档，并使用同名 .sha256 文件校验：

- xuanyan-v0.1.3-windows-x86_64.zip
- xuanyan-v0.1.3-linux-x86_64.tar.gz

Windows 桌面网页窗口需要系统 WebView2 Runtime；Linux 桌面窗口需要 GTK3，桌面
网页窗口还需要 WebKitGTK 4.1。这些是桌面运行库，不是玄言编译对 Rust 的依赖。

当前不包含安装器、数字签名、自动更新、远程包仓库、异步运行时、TLS、HTTP/2、
HTTP/3、用户 FFI、完整 IDE 或完整 macOS 发布承诺。未覆盖的原生语言组合继续报告
NBE001，不会回退到 Rust 后端、解释器或第二编译管线。
