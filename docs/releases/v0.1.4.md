# 玄言 v0.1.4 技术预览

发布日期：2026-08-01

玄言是一门以中文作为第一设计语言的原生静态类型编程语言。当前编译器使用 Rust
实现，但玄言用户程序只进入独立原生代码生成器，不依赖 Rust 工具链。自举是语言
成熟后的可能方向，不是 v0.1.4 承诺。

## 发布安全

- Windows 与 Linux 发布二进制使用 release profile 剥离内部符号。
- 私有工作区和 crate 源码路径在发布构建中重映射为通用 `src/...`。
- 打包门禁拒绝 `.rs`、PDB、私钥、私有服务器地址、访问令牌和内部源码路径。
- `SHA256SUMS` 使用独立 Ed25519 发布密钥签名，并随附 `SHA256SUMS.sig`。
- 发布公钥指纹：
  `SHA256:6O5UXW+dVTZyJOVJzHiKAsUGOTZF6hkhguoB+XqcCa4`。

## 本轮修复

- Windows 原生程序启动时初始化控制台输入和输出为 UTF-8；重定向到文件或管道时
  仍保持原始 UTF-8 字节流。
- Windows 与 Linux 的 `建立TCP连接` 通过系统地址解析器解析主机名，不再要求用户
  把域名改写成 IP 地址。
- 当前 v0.1 原生接受程序已覆盖并通过枚举、`可选`、`结果` 和 `可选<字符>` 相关
  的参数、返回值和匹配路径。旧版 v0.1.3 工具链上的 `NBE001` 观察不能直接代表
  v0.1.4；超出当前原生支持边界的组合仍会报告 `NBE001`。

## 当前边界

v0.1.4 仍是技术预览，不承诺旧语法、旧包格式或旧公共 API 兼容。当前不包含
安装器、操作系统信任链代码签名、自动更新、远程包仓库、异步运行时、TLS、
HTTP/2、HTTP/3 或用户 FFI。
