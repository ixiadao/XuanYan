# 玄言 v0.1.7 技术预览

发布日期：2026-08-02

v0.1.7 完成 HTTPS、JSON、编辑器工作流和离线安装闭环，并修复真实应用暴露的
编译诊断与原生代码生成问题。

## 本轮变化

- 新增有界阻塞式 `发送HTTPS请求`，支持方法、原始请求头、最多 16 MiB 的请求正文
  和正的毫秒超时，返回最终状态码、最终地址与最多 16 MiB 的响应正文原始字节。
  `获取HTTPS响应` 继续作为 GET 便捷函数复用同一宿主 ABI。
- JSON 包在同一事件列表上提供对象成员、数组元素、字符串、布尔值和数字文本读取；
  真实 HTTPS JSON 示例验证状态码、地址和响应字段。
- 修复 `*借用<字符串> == 字符串字面量` 及左右对称比较可能触发的 `INT001`，
  并补充显式泛型调用、匹配分支赋值和关键字绑定的定向诊断。
- VS Code 扩展新增检查、运行、构建、测试和格式化五个本地命令，继续复用已有 CLI
  与 LSP，不下载工具链或复制语言语义。
- Windows 与 Linux 工具链归档新增每用户离线安装与卸载脚本。安装完成后会输出
  `std`、`http` 和 `json` 的绝对本地依赖路径。

v0.1.7 仍是 x86_64 Windows 与 Linux 技术预览，不包含操作系统信任链代码签名、
自动更新、远程包仓库、完整响应头、流式 HTTPS、异步运行时、HTTP/2、HTTP/3、
用户 FFI 或完整 IDE。核心编译器和语言服务器源码继续保留在私有仓库。
