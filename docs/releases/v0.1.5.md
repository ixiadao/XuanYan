# 玄言 v0.1.5 技术预览

发布日期：2026-08-01

玄言是一门以中文为第一设计语言的静态类型编程语言。编译器目前使用 Rust 实现，
但发布版的玄言程序只进入独立原生代码生成管线，检查、运行、构建和测试不依赖
Rust 工具链。自举是长期方向，不是 v0.1.5 承诺。

## 本轮变化

- 新增最小阻塞式 `获取HTTPS响应`，使用系统证书信任链执行 HTTPS GET，返回最终
  状态码与最多 16 MiB 的完整正文原始字节。Windows 使用 WinHTTP，Linux 使用系统
  `libcurl.so.4`。
- 新增普通 `.xy` 本地包 `packages/json`，提供有界严格 JSON 文本解析与生成，并
  保留成员顺序、层级和数字原始文本。
- 新增真实 HTTPS JSON 示例，串联 HTTPS 状态检查、UTF-8 解码和严格 JSON 解析。
- 标准库源码按列表、文本与基础值、程序与控制台、文件与路径、网络、并发和桌面
  职责分域；包外仍使用 `依赖别名::公开名称` 逐个导入，不增加通配导入或重导出。
- HTTP/1.1 服务端包继续收紧请求行、请求头、分块扩展和尾部字段验证，并减少解析
  路径中的临时分配，不改变公开 API。
- 发布与公开仓库门禁检查当前树和完整 Git 历史，拒绝核心源码、PDB、私钥、令牌、
  私有服务器地址和内部源码路径进入 GitHub 或发布归档。

归档只包含预编译 CLI、LSP、公开玄言源码、示例、文档和第三方许可，不包含 Rust
编译器源码、Cargo 工作区、PDB、私钥或服务器配置。

GitHub 公开仓库同样不包含编译器和 LSP 的 Rust 实现源码。公开内容包括文档、
`corelib`、`stdlib`、`packages`、示例和发行资产；核心实现保留在私有源码仓库。

## 发布安全

- Windows 与 Linux 发布二进制使用 release profile 剥离内部符号。
- 私有工作区和 crate 源码路径在发布构建中重映射为通用路径。
- `SHA256SUMS` 使用仓库外独立 Ed25519 发布密钥签名，并随附
  `SHA256SUMS.sig`。
- 发布公钥指纹：
  `SHA256:6O5UXW+dVTZyJOVJzHiKAsUGOTZF6hkhguoB+XqcCa4`。

## 当前边界

v0.1.5 仍是技术预览，不承诺旧语法、旧包格式或旧公共 API 兼容。当前公开发布只
承诺 x86_64 Windows 与 Linux，不包含安装器、操作系统信任链代码签名、自动更新、
远程包仓库、完整 HTTP 客户端、异步运行时、HTTP/2、HTTP/3 或用户 FFI。
