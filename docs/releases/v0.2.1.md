# 玄言 v0.2.1 技术预览

状态：2026-08-04 发布为 GitHub 技术预览。

v0.2.1 收敛 v0.2.0 发布后的四平台同源业务能力，不增加第二编译管线、平台专用
语法或任意交叉编译目标。

## 本轮变化

- Windows、Linux、Android 与 HarmonyOS NEXT 复用同一份非 UI 玄言业务包，覆盖
  用户枚举、列表、JSON、HTTPS、应用沙箱文件和当前时间。
- Android 与 HarmonyOS NEXT 继续从同一 MIR 生成 `arm64-v8a` 共享库，并分别通过
  官方 SDK 构建和当前可用 arm64 真机自动验收。
- `HTTPS响应` 增加最终响应头，`packages/http` 只提供同一标准库 HTTPS 实现的薄
  转发与响应头首值查询。
- 移动原生后端补齐本轮业务包实际使用的整数、闭包、列表、枚举和宿主调用组合；
  未覆盖组合继续统一报告 `NBE001`，不回退到其他执行路径。
- Android 与 HarmonyOS NEXT 预览应用版本升级为 `0.2.1-preview`。

Windows/Linux 免源码工具链、VSIX 泄漏扫描、移动官方 SDK 构建和签名清单均已
复验。`v0.2.1` 使用独立标签和资产，不替换 v0.2.0。

## 当前边界

v0.2.1 不包含 macOS/iOS 发布支持、远程包仓库、调试器、异步运行时、任意移动
目标描述、用户 FFI、完整原生控件框架或跨平台 UI 框架。技术预览不承诺旧语法、
旧包格式、旧诊断或旧公共 API 兼容。
