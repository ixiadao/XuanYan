# 玄言 v0.1 语言参考

## 1. 文档地位

本文冻结玄言 v0.1 的源码语法和可观察语义。

- 编译管线和实现事实归属由
  [`xuanyan-v0.1-architecture.md`](xuanyan-v0.1-architecture.md) 说明。
- 本文是语法、类型、控制流、错误处理和所有权规则的唯一事实来源。
- 官方发布通过规范程序验证本文规定的成功值、诊断和释放顺序。
- 当前实现、内部测试、旧样例和生成代码不能覆盖本文。
- 本文未声明的语法在 v0.1 中一律无效，不提供旧语法别名。

## 2. 源文件与词法

玄言源文件使用 UTF-8，扩展名为 `.xy`。

### 2.1 标识符

标识符由中文字符、英文字母、十进制数字和下划线组成，首字符不能是数字。标识符区分大小写。

关键字不能作为标识符：

```text
公开 导入 常量 函数 结构体 枚举 协议 实现 为
令 变量 返回 如果 否则 当 循环 跳出 继续 遍历 在 匹配
真 假 非 且 或 自身 借用 可变借用
```

原始类型名和核心库登记名称也不能被同一作用域中的用户声明遮蔽。

### 2.2 公开名称

标准库、核心协议、LangItem 和稳定示例中的语言侧公开名称遵循以下规则：

| 类别 | 结构 | 示例 |
| --- | --- | --- |
| 工作包和文档标题 | 动作 + 对象 | 去除文本首尾空白 |
| 作用于首个值参数的操作 | 领域 + 动作 + 限定 | `文本追加`、`列表取出`、`文本去除首尾空白` |
| 外部资源或进程环境操作 | 动作 + 资源 | `读取文本文件`、`写入控制台`、`获取程序参数` |
| 属性 | 领域 + 属性 | `文本长度`、`程序参数数量` |
| 判断 | 领域 + 是 + 状态或类别 | `路径是文件`、`路径是目录` |
| 转换 | 到类型或从类型 | `到文本`、`从文本` |

动作词同时表达所有权和副作用：`追加` 修改现有值或资源并保留原内容，`连接`
返回组合后的新值，`取出` 移除并返回元素，`去除` 返回处理后的值，`删除` 用于
破坏性资源操作。公开名称保持简明，普通文件、Unicode 空白等精确边界由接口契约
说明，不堆入标识符。禁止使用 `文本首尾空白去除` 一类名词堆叠和动作名词化语序。

这些规则同时约束新增和已有公开名称。名称变化直接迁移全部调用和稳定文档，
不提供旧名称别名、兼容层或迁移开关。Rust 内部名称和普通诊断句子不属于语言侧
公开 API。

### 2.3 符号

- 分组、调用和元组形状使用 `()`。
- 块、结构体和枚举体使用 `{}`。
- 泛型参数和类型实参使用 `<>`。
- 参数、字段和类型参数之间使用 `,`。
- 名称与类型之间使用 `:`。
- 普通语句以 `;` 结束。
- 返回类型使用 `->`。
- 匹配分支使用 `=>`。
- 模块、枚举变体和关联函数限定使用 `::`。
- 字段和方法访问使用 `.`。

### 2.4 注释与空白

空格、制表符和换行只分隔记号。`//` 到行尾是注释。v0.1 不提供块注释和文档注释语法。

### 2.5 字面量

- 布尔字面量：`真`、`假`。
- 整数字面量：十进制数字，可在前面使用一元 `-`。
- 小数字面量：包含一个小数点的十进制数字，可在前面使用一元 `-`。
- 字符字面量：单引号包围的一个 Unicode 标量值，例如 `'玄'`。
- 字符串字面量：双引号包围的 UTF-8 文本，例如 `"玄言"`。

字符和字符串支持 `\n`、`\r`、`\t`、`\\`、`\'`、`\"` 和 `\u{十六进制码点}` 转义。

v0.1 不提供整数后缀、十六进制字面量、原始字符串和字符串插值。

## 3. 模块、声明与可见性

每个 `.xy` 文件定义一个模块。目录和文件名组成模块路径，路径段使用 `::`。

模块顶层允许：

- `导入`
- `常量`
- `函数`
- `宿主 函数`
- `结构体`
- `枚举`
- `协议`
- `实现`

声明默认只在当前模块可见。`公开` 使函数、结构体、枚举、协议以及结构体字段对其他模块可见。

### 3.1 导入

导入一个公开名称：

```xy
导入 工具::答案;
```

导入后在当前模块中直接使用 `答案`。v0.1 不提供通配导入、重命名导入、重导出和相对父模块语法。同一作用域导入重名名称是错误。

### 3.2 常量

常量只允许出现在模块顶层：

```xy
常量 答案: 整数 = 42;
```

常量必须显式声明类型并由编译期可求值表达式初始化。块级常量无效。

### 3.3 函数

```xy
函数 加一(值: 整数) -> 整数 {
    值 + 1
}
```

- 每个参数必须显式声明类型。
- 返回类型必须显式声明。
- 参数不可重新赋值。
- `返回 表达式;` 立即返回。
- 块尾无分号表达式是函数结果。
- 返回 `空` 的函数可以没有块尾表达式。
- 普通入口函数名为 `主函数`，由稳定入口 LangItem 登记。

入口返回普通 `空` 时，artifact 不写标准输出并以状态 0 退出；返回其他普通类型时，
使用该类型既有的显示语义把返回值写入标准输出，追加换行并以状态 0 退出。入口返回
核心 `结果<T, E>` 时：

- `结果::成功(值)` 使用 `T` 的既有显示语义把值写入标准输出，追加换行并以
  状态 0 退出。
- `结果::失败(错误)` 使用 `E` 的既有显示语义把错误写入标准错误，追加换行并以
  状态 1 退出，不写标准输出。

该特殊语义只由 Resolver 登记的核心 `结果`、`成功` 和 `失败` LangItem 身份
触发；用户声明的同名枚举仍是普通返回值。通过 `运行` 执行时，失败状态沿现有
原生 artifact 执行路径成为 `RBE003` 诊断，程序错误文本保持在诊断中。

v0.1 不提供默认参数、可变参数、函数重载和嵌套函数声明。

`宿主 函数` 用于声明编译器注册的固定宿主入口，没有函数体：

```xy
公开 宿主 函数 写入控制台(值: 借用<字符串>) -> 空;
```

宿主函数名称必须对应稳定 `HostFunctionId`，参数和返回值必须符合该入口的
运行时 ABI 表示。完整语言类型以玄言声明为准；该语法不能新增宿主实现，也
不提供用户 FFI。泛型宿主声明的每个具体调用还会在语义阶段按同一 ABI 登记
校验，不能用任意泛型实例绕过宿主要求。

## 4. 绑定、作用域与块

不可变绑定：

```xy
令 名称: 类型 = 值;
令 推断名称 = 值;
```

可变绑定：

```xy
变量 名称: 类型 = 值;
变量 推断名称 = 值;
```

规则：

- 每个局部绑定必须有初始化表达式。
- 省略类型时从初始化表达式推断。
- `令` 绑定不能重新赋值。
- `变量` 绑定可以通过 `名称 = 表达式;` 重新赋值。
- 赋值目标只允许可变局部绑定、`*可变借用值`，或以它们为根的结构体字段。
- 不可变局部、常量和共享借用根上的字段不能被赋值。
- 内层块可以遮蔽外层名称。
- 名称从声明完成后可见，到所属块结束。
- 普通表达式语句和赋值语句必须以 `;` 结束。
- 块尾无分号表达式是块结果。

旧 `绑定`、`可变 变量` 和未初始化局部声明均为语法错误。

## 5. 类型

### 5.1 原始类型

编译器直接支持：

```text
空
布尔
字符
字符串
整数
小数
字节
有符号8 有符号16 有符号32 有符号64
无符号8 无符号16 无符号32 无符号64
```

- `整数` 使用有符号 64 位语义。
- `小数` 使用 IEEE 754 双精度语义。
- `字符` 是 Unicode 标量值。
- `字符串` 是拥有所有权的 UTF-8 字符串。
- `字节` 是无符号 8 位值。
- 算术溢出在常量求值时产生编译诊断，在运行时产生统一终止错误。
- 环绕运算只能通过显式核心库函数使用。
- 字符串不支持整数索引；字符或字节访问由库方法提供。

### 5.2 普通类型

用户类型和核心库类型统一使用名称加类型参数：

```xy
盒子<整数>
可选<字符串>
结果<整数, 错误>
```

`可选`、`结果`、集合、资源和用户类型都是普通 ADT。编译器内部只通过 `DefId`、类型实参和少量稳定 LangItem 识别必要语义。

v0.1 不提供元组类型、数组类型、类型别名、高阶类型、动态协议对象、裸指针和用户可见函数指针类型。

### 5.3 借用类型

```xy
借用<字符串>
可变借用<计数器>
```

借用类型只能用于函数参数和局部绑定，不能作为结构体字段、枚举载荷或函数返回类型。源码中没有生命周期参数。

### 5.4 最小标准库与程序参数

`std` 是随编译器提供的普通玄言包。v0.1 冻结以下公开接口和可观察语义：

| 接口 | 可观察语义 |
| --- | --- |
| `列表<T>`、`列表创建<T>() -> 列表<T>` | 创建拥有所有权的空列表。 |
| `写入控制台(借用<字符串>) -> 空` | 向标准输出写入文本，不自动添加换行。 |
| `写入错误输出(借用<字符串>) -> 空` | 向标准错误写入文本，不自动添加换行。 |
| `程序参数数量() -> 整数` | 返回程序参数数量。 |
| `获取程序参数(整数) -> 可选<字符串>` | 按从零开始的下标返回参数；负数或越界返回 `可选::空值`。 |
| `获取必需程序参数(整数, 字符串) -> 结果<字符串, 字符串>` | 按从零开始的下标返回成功参数；负数或越界返回调用者提供的错误文本。 |
| `读取环境变量(借用<字符串>) -> 结果<字符串, 字符串>` | 读取当前进程环境中的 UTF-8 值；变量缺失、名称无效或值不是有效 UTF-8 时返回非空失败消息。 |
| `获取当前目录() -> 结果<字符串, 字符串>` | 返回当前进程工作目录的完整 UTF-8 路径；目录读取失败或路径不是有效 UTF-8 时返回非空失败消息。 |
| `获取临时目录() -> 结果<字符串, 字符串>` | 返回宿主为当前进程选择的 UTF-8 临时目录路径；路径不是有效 UTF-8 时返回非空失败消息。 |
| `创建临时目录() -> 结果<字符串, 字符串>` | 在宿主临时目录根路径下原子创建新的空目录并返回实际 UTF-8 路径；名称冲突会重试，创建失败或路径不是有效 UTF-8 时返回非空失败消息。 |
| `创建临时文件() -> 结果<字符串, 字符串>` | 在宿主临时目录根路径下原子创建新的空普通文件并返回实际 UTF-8 路径；名称冲突会重试，创建失败或路径不是有效 UTF-8 时返回非空失败消息。 |
| `运行桌面窗口(借用<字符串>, 整数, 整数) -> 结果<空, 字符串>` | 使用标题、宽度和高度创建宿主顶层窗口并阻塞到窗口关闭；标题必须非空且不含 NUL，尺寸必须是正的 32 位有符号整数。Windows 使用 USER32，Linux 动态装载系统 GTK3；参数、运行库初始化或窗口创建失败时返回非空失败消息。 |
| `运行桌面网页窗口(借用<字符串>, 借用<字符串>, 整数, 整数) -> 结果<空, 字符串>` | 使用标题、地址、宽度和高度创建宿主桌面网页窗口并阻塞到窗口关闭；标题和地址必须非空且不含 NUL，尺寸必须是正的 32 位有符号整数。Windows 使用 USER32 与 WebView2，Linux 动态装载系统 GTK3 与 WebKitGTK 4.1；参数、运行库初始化或窗口创建失败时返回非空失败消息。 |
| `显示桌面确认框(借用<字符串>, 借用<字符串>) -> 结果<布尔, 字符串>` | 使用非空标题和内容显示宿主确认框并阻塞到用户选择；确认返回 `真`，否定或关闭返回 `假`。标题和内容不得包含 NUL；Windows 使用 USER32，Linux 动态装载系统 GTK3，参数、运行库初始化或对话框创建失败时返回非空失败消息。 |
| `读取标准输入() -> 结果<字符串, 字符串>` | 读取当前进程剩余标准输入直到 EOF；空输入成功返回空字符串，读取错误或无效 UTF-8 返回非空失败消息。 |
| `读取标准输入行() -> 结果<可选<字符串>, 字符串>` | 读取当前进程标准输入下一行并去除 `\n` 或 `\r\n` 行结束符；有行成功返回 `可选::有值`，EOF 成功返回 `可选::空值`，读取错误或无效 UTF-8 返回非空失败消息。 |
| `读取文本输入(整数) -> 结果<字符串, 字符串>` | 指定下标存在程序参数时把参数作为 UTF-8 文件路径读取；缺少参数时读取标准输入。 |
| `读取文本文件(借用<字符串>) -> 结果<字符串, 字符串>` | 读取完整 UTF-8 文本；文件错误或无效 UTF-8 返回非空失败消息。 |
| `读取二进制文件(借用<字符串>) -> 结果<列表<字节>, 字符串>` | 读取文件的完整原始字节；保留 NUL、非 UTF-8 和边界字节，文件错误返回非空失败消息。 |
| `读取目录(借用<字符串>) -> 结果<列表<字符串>, 字符串>` | 返回目录的直接子项路径，按路径文本排序；目录错误或无法表示为 UTF-8 的子项路径返回非空失败消息。 |
| `读取目录文件(借用<字符串>) -> 结果<列表<字符串>, 字符串>` | 返回目录中的直接普通文件路径，保持 `读取目录` 的路径文本顺序；目录读取或文件类型查询错误返回非空失败消息。 |
| `路径是空目录(借用<字符串>) -> 结果<布尔, 字符串>` | 判断现有目录是否没有直接子项；目录为空时成功返回 `真`，目录包含子项时成功返回 `假`，目录读取错误返回非空失败消息。 |
| `路径连接(借用<字符串>, 借用<字符串>) -> 字符串` | 使用宿主路径组合规则连接基础路径和子路径；绝对子路径遵循宿主替换语义，返回文本保持 UTF-8。 |
| `路径文件名(借用<字符串>) -> 结果<字符串, 字符串>` | 返回路径的末级路径分量；路径不要求存在，空路径、根路径、没有末级分量或名称不是有效 UTF-8 时返回非空失败消息。 |
| `路径父目录(借用<字符串>) -> 结果<字符串, 字符串>` | 返回路径的词法父目录；路径不要求存在，空路径、根路径、单层相对路径、没有父目录或父目录不是有效 UTF-8 时返回非空失败消息。 |
| `路径扩展名(借用<字符串>) -> 可选<字符串>` | 返回末级路径分量的扩展名；路径不要求存在，无扩展名返回 `可选::空值`，多点文件名、隐藏文件和尾随点遵循宿主 `Path` 规则。 |
| `路径扩展名是(借用<字符串>, 借用<字符串>) -> 布尔` | 判断末级路径分量的最后一个扩展名是否与不带点的目标扩展名精确相同；比较区分大小写，无扩展名返回 `假`。 |
| `路径文件主名(借用<字符串>) -> 可选<字符串>` | 返回末级路径分量去掉最后一个扩展名后的主名；路径不要求存在，没有末级分量返回 `可选::空值`，多点文件名、隐藏文件和尾随点遵循宿主 `Path` 规则。 |
| `路径是绝对路径(借用<字符串>) -> 布尔` | 按宿主 `Path` 规则判断路径文本是否为绝对路径；不要求路径存在。 |
| `删除文件(借用<字符串>) -> 结果<空, 字符串>` | 删除单个文件；路径不存在、目标是目录或其他文件系统错误返回非空失败消息。 |
| `删除目录(借用<字符串>) -> 结果<空, 字符串>` | 删除单个空目录；路径不存在、目标是普通文件、目录非空或其他文件系统错误返回非空失败消息。 |
| `删除目录树(借用<字符串>) -> 结果<空, 字符串>` | 递归删除现有目录及其内容；路径不存在、目标是普通文件或其他文件系统错误返回非空失败消息。 |
| `路径是文件(借用<字符串>) -> 结果<布尔, 字符串>` | 查询路径的宿主元数据；普通文件返回成功 `真`，目录和其他非普通文件返回成功 `假`，查询错误返回非空失败消息。 |
| `路径是目录(借用<字符串>) -> 结果<布尔, 字符串>` | 查询路径的宿主元数据；目录返回成功 `真`，普通文件和其他非目录路径返回成功 `假`，查询错误返回非空失败消息。 |

`列表取出`、`列表取出末项` 和 `列表取出指定项` 都从同一个拥有列表移出元素，
成功后列表长度减一；前两者分别按最早和最后追加顺序消费，后者按从零开始的下标
消费。三者都不复制元素；空列表、负数或越界下标返回 `可选::空值`，失败时列表
保持不变。

`列表反转` 修改同一个拥有列表的元素顺序，不创建第二个列表，也不复制元素。反转
前后列表长度相同；空列表和单元素列表保持原状，重复元素完整保留。

`列表清空` 修改同一个拥有列表，直接移除全部元素，不创建第二个列表，也不复制
元素。空列表和重复调用保持成功；调用后列表长度为零。

`列表连接` 是普通标准库函数。它把左侧拥有列表作为结果，按现有 `可遍历<T>`
协议消费右侧列表，并用 `列表追加` 移动元素；结果先保留左侧顺序，再追加右侧
顺序，不复制元素。两个输入列表都在调用后被消费；空列表和重复值按相同顺序规则
处理。

`文本是空` 和 `列表是空` 是普通标准库函数，分别复用 `文本长度` 和 `列表长度`。
文本只在 Unicode 标量数量为零时返回 `真`，列表只在元素数量为零时返回 `真`；
两个函数都只读取共享借用，不改变输入，也不复制列表元素。

`文本到UTF8字节` 只读取借用文本并按原顺序复制完整 UTF-8 编码到新的拥有列表；
输入文本保持可继续使用。`从UTF8字节` 只读取借用列表并严格校验完整 UTF-8 序列；
成功时复制原始字节到新的拥有字符串，空列表成功返回空字符串。无效、截断或过长
编码返回非空失败消息，不执行替换字符修复、编码猜测或部分转换，输入列表保持不变。

核心 `到文本` 协议为全部基础类型提供标准库实现。调用只读取共享借用，转换后
原值仍可继续使用。

| 类型 | `到文本` 结果 |
| --- | --- |
| `空` | `空` |
| `布尔` | `真` 或 `假` |
| `字符` | 该 Unicode 标量本身，不增加引号或转义 |
| `字符串` | 内容相同的新字符串 |
| `整数`、`字节`、固定宽度整数 | 十进制 ASCII，无分隔符和前导零；负数使用 ASCII `-` |
| 有限 `小数` | 可往返的最短十进制表示；没有小数点或指数标记时追加 `.0` |
| 非有限 `小数` | `NaN`、`inf` 或 `-inf` |

用户 ADT 不自动获得 `到文本`；需要时必须显式实现该静态协议。该能力不提供
隐式字符串转换、格式字符串、精度、进制或本地化选项。

核心静态协议 `从文本` 把完整字符串严格解析为基础标量：

```xy
公开 协议 从文本 {
    函数 从文本(文本值: 借用<字符串>) -> 结果<自身, 字符串>;
}
```

标准库为 `布尔`、`字符`、`整数`、`小数`、`字节` 和全部固定宽度整数实现该
协议。`空`、`字符串` 和用户 ADT 不自动获得实现。调用形式为
`整数::从文本(文本)`；成功返回 `结果::成功(值)`，无效格式、空输入或
越界返回带非空消息的 `结果::失败`，不返回部分结果、不终止 artifact，也不写
标准输出或标准错误。

- 输入按完整字符串解析，不自动去除前后空白，也不依赖区域设置或平台编码。
- `布尔` 只接受 `真` 和 `假`。
- `字符` 只接受恰好一个 Unicode 标量值，不解析引号或字面量转义。
- 整数只接受十进制 ASCII 数字；有符号整数可带一个前导 `-`，无符号整数和
  `字节` 不接受符号。空白、分隔符、进制前缀、类型后缀和 Unicode 数字均失败，
  数值还必须落入目标类型范围。
- 普通 `小数` 可带一个前导 `-`，必须有整数位；小数点后必须有数字；指数使用
  `e` 或 `E`，可带 `-` 但不接受 `+`。精确文本 `NaN`、`inf` 和 `-inf` 有效，
  普通文本解析为非有限值时失败。
- 每个受支持基础值的 `到文本()` 结果都能由对应类型的 `从文本()` 恢复。

`读取环境变量` 每次直接读取当前进程环境，不保存环境快照。变量名称和值都使用
UTF-8 文本；空名称、包含 `=` 或 NUL 的名称、缺失变量以及非 UTF-8 值返回非空
失败消息。标准库不提供环境变量写入、删除或枚举接口，宿主错误的完整措辞不是
稳定语义。

文件路径使用玄言 `字符串` 表示，相对路径以 artifact 的实际进程工作目录为
基准。`路径连接` 使用宿主 `Path::join` 组合两个路径文本；普通子路径使用宿主
平台分隔符，绝对子路径遵循宿主的替换语义。读取不做换行、编码或 Unicode 规范化；
写入不自动创建父目录。`创建目录` 使用宿主递归目录创建语义，已存在的目录成功，
缺失的父目录一并创建。路径组合结果无法表示为 UTF-8 时只报告宿主运行时错误，
不引入第二套语言路径表示。失败消息保证非空，但操作系统的完整错误措辞不是稳定
语义。`路径文件名` 只做词法路径分解，使用宿主 `Path::file_name` 取得末级路径分量，
再转换为 UTF-8 文本；它不访问文件系统、不规范化路径、不解析扩展名或文件 stem。
路径不存在不影响成功，没有末级分量或名称无法表示为 UTF-8 时返回失败。
`路径父目录` 使用宿主 `Path::parent` 取得非空词法父路径并转换为 UTF-8 文本；
它同样不访问文件系统、不规范化路径、不解析符号链接。绝对路径和带父分量的相对
路径都可成功；空路径、根路径、单层相对路径和其他没有非空父目录的路径返回失败。
`路径扩展名` 使用宿主 `Path::extension` 取得末级路径分量的扩展名并转换为 UTF-8
文本；它不访问文件系统、不规范化路径、不解析符号链接。无扩展名返回
`可选::空值`，多点文件名、隐藏文件和尾随点的结果遵循宿主路径规则。
`路径扩展名是` 是普通标准库函数，复用 `路径扩展名`、`文本长度` 和 `文本开头是`
判断完整相等。它只比较最后一个扩展名，区分大小写，不移除目标扩展名前导点，也不
访问文件系统或规范化路径。无扩展名返回 `假`；尾随点产生的空扩展名可以与空目标
扩展名匹配。
`路径文件主名` 使用宿主 `Path::file_stem` 取得末级路径分量去掉最后一个扩展名
后的主名并转换为 UTF-8 文本；它保持相同的纯词法边界。`archive.tar.gz` 返回
`archive.tar`，`.env` 返回 `.env`，`report.` 返回 `report`，`README` 返回
`README`，根路径和其他没有末级路径分量的输入返回 `可选::空值`。
`路径是绝对路径` 使用宿主 `Path::is_absolute` 进行纯词法判断，不访问文件系统、
不拼接当前目录、不规范化路径、不解析符号链接；盘符、UNC 路径和其他平台差异
继续遵循宿主路径规则。空路径和普通相对路径返回 `假`。
`路径规范化` 使用宿主文件系统把已有相对路径、`.` 和 `..` 解析为绝对 UTF-8
路径，并按宿主规范化规则解析路径中的符号链接；缺失路径、无效路径、宿主错误或
结果无法表示为 UTF-8 时返回失败，输入路径保持不变。返回文本的前缀、分隔符和
大小写细节遵循宿主平台，不构成跨平台稳定语义。它是标准库唯一访问文件系统的
路径规范化入口；`路径连接`、路径分解和 `路径是绝对路径` 继续保持纯词法语义。

`读取目录` 只枚举给定目录的直接子项，不递归、不筛选文件类型。每项使用宿主
路径表示，可直接传给现有文件接口；结果按 UTF-8 路径文本升序排列，空目录成功
返回空列表。`读取目录文件` 是普通标准库函数，按 `读取目录` 的既有顺序遍历直接
子项，使用 `路径是文件` 筛选普通文件，并通过 `列表追加` 返回拥有路径列表；它不
递归、不缓存目录内容，也不引入元数据对象或第二套路径表示。空目录和仅含子目录的
目录返回空列表，目录读取或任一文件类型查询失败时原样传播非空错误。
`路径是空目录` 是普通标准库函数，复用 `读取目录` 与 `列表是空`；只在直接子项
数量为零时成功返回 `真`，并原样传播目录不存在、普通文件和读取失败的非空错误，
输入路径保持不变。`路径是文件` 使用宿主元数据判断普通文件，符号链接和其他路径
类型的解释继续遵循宿主平台。`路径是目录` 使用同一宿主元数据判断目录，
普通文件和其他非目录路径返回 `假`，查询失败才返回失败；它不增加通用文件类型
枚举或第二套元数据表示。`路径存在` 使用宿主可报告错误的存在性查询；普通文件、
目录和其他已有路径返回 `真`，缺失路径返回 `假`，其他查询错误返回失败。它不替代
路径类型查询，不规范化、解析或缓存路径，输入路径保持不变。`删除文件` 只调用宿主单文件删除，不递归
删除目录；删除不存在的路径或目录返回失败。`删除目录` 只调用宿主空目录删除，
不递归删除目录树；删除不存在的路径、普通文件或非空目录返回失败。
`删除目录树` 直接调用宿主递归目录删除；现有目录及其内容删除成功后根路径不再
存在，缺失路径、普通文件和其他宿主错误返回非空失败消息。它不在玄言侧遍历、
筛选或缓存目录项，权限、符号链接和并发竞态沿用宿主平台。
`写入文本文件` 每次调用创建目标文件或完整截断已有文件，并写入借用内容的全部
UTF-8 字节；空内容创建或截断为零字节文件，不创建缺失的父目录。路径和内容借用
保持不变，打开、写入或关闭失败返回非空失败消息。
`追加写入文本文件` 每次调用创建或打开一个文件并写入完整 UTF-8 内容，不创建缺失的
父目录，不添加换行或其他分隔符；目标文件和父目录错误返回失败。
`读取二进制文件` 直接读取文件的完整原始字节并返回拥有所有权的
`列表<字节>`，不执行 UTF-8 校验、编码猜测、换行转换或文本回退；空文件成功
返回空列表，文件系统错误返回非空失败消息。列表仍使用标准库现有单泛型列表载体，
字节顺序与宿主 `std::fs::read` 返回顺序一致。
`写入二进制文件` 直接将借用的 `列表<字节>` 的完整原始字节写入目标文件，
不执行 UTF-8 校验、编码转换、追加或文本回退；已有目标文件被完整覆盖，不创建
缺失的父目录，空列表会得到空文件，文件系统错误返回非空失败消息。
`追加写入二进制文件` 直接将借用列表中的完整原始字节追加到目标文件，不执行
UTF-8 校验、编码转换或文本回退；已有内容保持不变，目标缺失时创建文件，但不创建
缺失的父目录。空列表不改变已有文件，目标缺失时仍创建空文件；输入列表保持不变，
文件系统错误返回非空失败消息。
`复制文件` 复制单个文件的完整字节，不要求内容是有效 UTF-8；已有目标文件被
覆盖，但不会创建缺失的目标父目录，也不递归复制目录树。源路径不存在、源是目录
或其他宿主文件系统错误返回失败；权限和符号链接等细节继续遵循宿主平台。
`重命名路径` 直接使用宿主文件系统重命名语义，不复制后删除、不创建缺失的目标
父目录，也不模拟跨文件系统移动。目标覆盖、目录、权限和符号链接等细节继续遵循
宿主平台；任何宿主错误都返回非空失败消息。
`文件大小` 读取宿主元数据中的字节长度，只接受普通文件，并显式检查宿主无符号
长度能否表示为玄言 `整数`。它不读取文件内容，也不暴露权限、文件类型枚举或通用
元数据对象；符号链接的解释继续遵循宿主 `metadata` 语义。`文件修改时间` 使用同一
普通文件边界，读取 `metadata.modified()` 并转换为相对 `UNIX_EPOCH` 的完整秒数；
时间早于 epoch、宿主元数据错误或结果不能表示为 `整数` 时返回非空失败消息，不提供
时区、格式化或精度配置。

`TCP监听器` 和 `TCP连接` 都是普通公开 ADT，但唯一源码字段不公开，调用方不能使用
结构体字面量或完整结构体模式伪造、拆解资源。监听器直接拥有宿主 `TcpListener`，
连接直接拥有宿主 `TcpStream`；整体移动时底层资源随值移动，拥有值离开作用域时沿
既有 MIR `Drop` 恰好关闭一次。标准库不提供整数句柄、全局资源表、无效资源哨兵、
完整显式关闭、接收方向关闭、克隆、套接字读写超时、非阻塞模式或异步接口。

`建立TCP监听器` 只读取地址文本，并把地址解析、绑定和监听交给宿主同步网络实现。
`TCP监听器本地地址` 共享借用已绑定监听器，读取宿主实际本地地址并返回
`SocketAddr` 的文本表示；它不缓存地址，也不提供结构化地址字段。
`TCP监听器等待连接` 只等待一个监听器的可接受事件，不接受连接或修改监听器。
`TCP监听器接受连接` 共享借用监听器并执行一次阻塞接受，成功时返回拥有
`TCP连接`，监听器本身保持可继续接受后续连接。
`建立TCP连接` 只读取地址文本，并把地址解析和连接交给宿主同步网络实现。
`TCP连接本地地址` 共享借用已建立或已接受连接，读取宿主 `TcpStream::local_addr()`
并返回 `SocketAddr` 的文本表示；它不缓存地址，也不提供结构化地址字段。
`TCP连接对端地址` 共享借用已建立或已接受连接，读取宿主 `TcpStream::peer_addr()`
并返回 `SocketAddr` 的文本表示；它不缓存地址，也不提供结构化地址字段。
`TCP连接等待读取` 通过可变借用独占等待一个连接的可读取事件，不读取数据或消费连接；返回 `真`
后仍须调用 `TCP连接接收字节` 区分数据、对端关闭和系统错误。
`TCP连接列表等待读取` 共享借用拥有连接列表，等待列表中的连接并按稳定列表顺序返回
首个就绪下标；空列表和超时都返回 `可选::空值`，连接和列表保持不变。
`TCP监听器与连接列表等待事件` 在同一宿主等待集合中把监听器放在槽位 `0`，把连接列表按
稳定顺序放在槽位 `1..`；因此连接槽位减一就是列表下标，监听器与连接同时就绪时监听器优先。
它不接受连接、不读取数据，也不修改监听器、连接或列表。四个等待函数都接受
`-1` 或不超过 `2147483647` 的非负毫秒数，其他值返回失败。
`TCP连接发送字节` 使用完整写入语义；成功表示输入列表中的全部字节已经交给宿主
套接字，输入列表保持不变。`TCP连接关闭发送` 直接关闭同一宿主连接的本地发送方向；
成功后不能再承诺继续发送，但同一连接仍可接收对端响应。重复关闭的成功或失败结果
遵循宿主平台，不构成稳定语义。`TCP连接接收字节` 要求最大字节数大于零，按该上限
准备缓冲区并只执行一次阻塞读取；成功的有值列表长度在一到该上限之间，读取零字节
表示对端有序关闭。地址解析、绑定、监听、连接本地和对端地址查询、等待、接受、连接、
分配、写入、关闭发送和读取错误都通过现有 `结果::失败` 返回非空消息；操作系统完整
措辞、宿主地址文本、DNS 结果和网络时序不是跨平台稳定语义。

`线程` 是普通公开 ADT，但其唯一源码字段不公开，调用方不能使用结构体字面量或
完整结构体模式伪造、拆解句柄。每个值直接拥有一个宿主线程句柄；整体移动时句柄
随值移动，`等待线程` 按值消费句柄，因此同一线程不能重复等待。线程值未等待即
离开作用域时只分离子线程，不在普通释放中阻塞，也不提供显式取消或强制终止。

标准库目前用泛型宿主声明表达 `启动线程` 的任务参数，因为 v0.1 源码类型语法尚未
提供函数类型标注；这不是任意泛型能力。每个具体调用的任务类型必须是无参数且返回
`结果<空, 字符串>` 的函数值，其他类型在语义阶段拒绝。任务按值移动进子线程；
闭包捕获也按现有拥有语义移动，包含借用的捕获在进入 HIR 前拒绝。
当前原生固定线程任务支持零个、一个或两个捕获；两个捕获都必须是已有支持范围内的
单机器字标量或拥有值。字符串占用两个机器字，不能与第二个捕获组合。

子线程使用与父执行路径相同的生成函数和宿主 ABI，但创建独立 `Runtime`，只复制
程序参数；父子线程不共享 `&mut Runtime`。`等待线程` 成功表示任务已经完成，
任务返回的失败文本和任务执行错误原样进入失败载荷，panic 返回稳定的非空失败消息。
建立失败的宿主错误措辞和 panic 的具体宿主载荷不是跨平台稳定语义。当前不提供线程
名称、优先级、作用域线程、线程池、锁、超时、取消或异步运行时。

`原子整数` 是普通公开 ADT，但其唯一源码字段不公开，调用方不能使用结构体字面量
或完整结构体模式伪造、拆解载体。每个生成值直接拥有一个
`Arc<AtomicI64>`；普通移动只移动该拥有载体，`原子整数复制` 共享借用原载体并
返回指向同一原子状态的新拥有载体。最后一个载体释放时底层状态随普通 MIR `Drop`
释放，不使用整数句柄、全局原子表或第二套并发运行时。

`原子整数读取`、`原子整数写入`、`原子整数交换`、`原子整数比较交换` 和
`原子整数增加` 都只共享借用载体，因此调用后原载体仍可继续使用；交换和增加返回
更新前的旧值。比较交换成功时返回被替换的旧值，失败时返回本次观察到的当前值且不
修改状态。七个操作固定使用顺序一致性，比较交换固定使用强比较交换；增加按补码
环绕，负增量覆盖减少需求，不公开内存顺序枚举、弱比较交换或独立减法选项。当前不
提供其他原子算术、布尔原子、显式关闭或隐式深复制。

`通道<T>` 是公开的单泛型聚合 ADT，只含公开 `发送端` 和 `接收端` 字段；两个端点
分别是公开单泛型 ADT，但各自唯一的源码字段不公开。调用方不能伪造端点，只能用完整
结构体模式整体消费通道并取得两个端点。`通道发送端复制` 共享借用一个发送端，保留
原端点并返回同一通道的独立拥有发送端；接收端保持唯一且不可复制。端点随普通移动和
MIR `Drop` 释放；最后一个发送端释放后接收端在排空已发送值后返回 `可选::空值`，
接收端释放后发送失败并归还本次移动的原载荷。

`通道接收状态<T>` 是公开单泛型枚举，变体顺序和载荷固定为 `收到(T)`、`暂无值`、
`已断开`。`通道尝试接收` 只共享借用接收端并立即调用宿主的非阻塞接收语义；队列
暂空且仍有发送端时返回 `暂无值`，队列排空且全部发送端断开时返回 `已断开`，收到值
时移动一个拥有载荷并返回 `收到(载荷)`。该操作不移动接收端，调用后仍可继续发送或
接收。

`创建通道`、`通道发送端复制`、`通道发送`、`通道接收` 和 `通道尝试接收` 分别直接
对应同步创建、发送端复制、发送、阻塞接收和一次非阻塞状态接收。通道没有全局句柄表、
显式关闭、多接收端、超时、选择、锁或异步执行器；每个通道始终只拥有一个接收端。

标准输入读取同样不做换行、NUL 或 Unicode 规范化。每次调用消费当前标准输入
尚未读取的全部字节直到 EOF；有效 UTF-8 原样返回，空输入与失败保持可区分。
`读取标准输入行` 每次只消费当前标准输入的下一行，去除行末的 `\n`，以及紧邻
它之前的 `\r`；没有更多字节时成功返回 `可选::空值`，没有换行符的最后一段仍
作为一行返回。重复调用继续消费同一个标准输入，不把剩余输入保存为玄言字符串或
列表；读取错误和无效 UTF-8 返回非空失败消息。
`读取文本输入` 是普通标准库函数：指定下标存在程序参数时，只把该参数交给
`读取文本文件`；缺少参数时，只调用 `读取标准输入`。它原样保留两个底层接口的
UTF-8、错误和消费语义，不增加输入源对象、环境变量回退、编码猜测或第二套 I/O
路径。

`获取当前目录` 直接读取当前进程的工作目录，不执行目录切换、规范化、解析符号链接或
缓存结果。宿主路径只有在能转换为有效 UTF-8 时才作为成功文本返回；目录读取错误和
非 UTF-8 路径都返回非空失败消息。

`获取临时目录` 直接读取宿主为当前进程选择的临时目录候选路径，不创建、清理、验证或
缓存目录，也不执行规范化或解析符号链接。宿主路径只有在能转换为有效 UTF-8 时才
作为成功文本返回；非 UTF-8 路径返回非空失败消息。

`创建临时目录` 在同一宿主临时目录根路径下使用原子目录创建语义独占一个新的空
目录；名称冲突时改用下一候选名称，不执行先检查后创建。成功值是已经创建且可表示
为 UTF-8 的实际路径，连续成功调用返回不同路径。该接口不接收前缀或随机数，不返回
文件句柄或临时资源对象，也不自动清理；调用方继续通过现有文件接口和 `删除目录`
显式管理内容与生命周期。创建失败和候选路径无法表示为 UTF-8 都返回非空失败消息，
且不会返回未创建的候选路径。

`创建临时文件` 在同一宿主临时目录根路径下使用原子独占文件创建语义创建新的零
字节普通文件；名称冲突时改用下一候选名称，不执行先检查后创建。成功值是已经创建
且可表示为 UTF-8 的实际路径，连续成功调用返回不同路径。该接口不接收前缀或随机
数，不返回文件句柄或临时资源对象，也不自动清理；调用方通过现有读写、文件大小和
删除接口管理内容与生命周期。创建失败和候选路径无法表示为 UTF-8 都返回非空失败
消息，且不会返回未创建的候选路径。

`运行桌面窗口` 只提供单个阻塞式宿主顶层窗口。调用成功后，当前玄言线程进入宿主
消息循环，直到用户关闭窗口才返回 `结果::成功(空)`。Windows artifact 直接导入
USER32；Linux artifact 只在调用该函数时动态装载系统 GTK3。该接口不提供窗口句柄、
控件、绘制、事件回调、WebView、异步循环或跨线程窗口操作。

`运行桌面网页窗口` 创建一个可移动、缩放、最小化、最大化和关闭的宿主顶层窗口，
并让网页视图跟随窗口客户区尺寸变化。调用在当前玄言线程阻塞到窗口关闭后返回
`结果::成功(空)`。Windows artifact 使用系统 WebView2 Runtime，构建时在产物旁写入
`WebView2Loader.dll` 与许可文件；Linux artifact 动态装载 GTK3 和
`libwebkit2gtk-4.1.so.0`。该接口只负责显示给定地址，不提供窗口句柄、导航控制、
JavaScript 消息桥、异步事件流、多窗口管理或应用资源打包。

`显示桌面确认框` 使用宿主原生的确认对话框和按钮文本，并在当前玄言线程阻塞到
用户确认、否定或关闭。Windows artifact 调用 `MessageBoxW`；Linux artifact 动态
装载 GTK3 消息对话框。该接口只返回一次布尔选择，不提供自定义按钮文本、窗口句柄、
持续事件流、回调或对话框状态。

`写入控制台` 与 `写入错误输出` 分别把共享借用文本的完整 UTF-8 字节写入当前进程
标准输出和标准错误，不自动增加换行、前缀或格式。二者不保存输出状态，也不提供
日志级别、颜色、模板或全局配置。

`文本追加` 不增加分隔符、换行、引号或转义，也不执行 Unicode 规范化；空片段
是成功的空操作。目标字符串仍由调用方拥有，借用结束后可以继续使用。动态基础值
必须先显式调用 `到文本()`，再把结果追加到目标字符串；该能力不提供隐式转换、
字符串插值、格式语言或 `字符串 + 字符串` 运算。

`文本连接` 是普通标准库函数，移动两个已拥有字符串并复用 `文本追加` 返回组合
结果；空字符串按原样参与连接。它适合一次组合两个片段，不隐式复制输入，也不
替代需要保留目标或循环追加多个片段的 `文本追加`。

```xy
令 数值: 整数 = 42;
令 输出 = 文本连接("总和：", 数值.到文本());
```

`文本分行` 只读取共享借用的完整字符串，并返回拥有所有权的 `列表<字符串>`。
`\n` 和 `\r\n` 作为行终止符且不进入记录；单独的 `\r` 保留在记录内容中。
空字符串返回空列表，末尾终止符不产生额外空记录，连续终止符之间保留内部空
记录。该操作不去除空白、不做 Unicode 规范化，也不依赖平台换行常量；返回列表
可以直接由 `遍历` 消费，随后使用 `从文本` 对每条记录进行严格解析。

`文本分割` 只读取文本和分隔符的共享借用，按非空分隔符的精确 UTF-8 子串匹配
返回拥有所有权的 `列表<字符串>`，两个输入值都保持不变。前导、尾随和连续
分隔符产生的空字段全部保留；未找到分隔符时返回只包含原文本的列表，空输入返回
只包含空文本的列表。空分隔符返回带非空消息的 `结果::失败`，不会隐式改为按字符
边界分割。该操作不去除空白、不执行 Unicode 规范化、正则匹配或语言分词。

`文本替换` 只读取原文本、原片段和新片段的共享借用，从左到右按精确 UTF-8
子串替换全部不重叠命中，返回独立拥有的新字符串；三个输入值都保持不变。未找到
原片段时返回与原文本内容相同的新字符串，空新片段表示删除全部命中。空原片段返回
带非空消息的 `结果::失败`，不会在字符边界之间隐式插入。该操作不执行 Unicode
规范化、大小写折叠、正则匹配或语言分词。

`文本查找` 只读取文本和片段的共享借用，返回首个精确 UTF-8 子串命中的从零开始
Unicode 标量下标；两个输入值都保持不变。未命中返回 `可选::空值`，空片段返回
`可选::有值(0)`。返回值不是 UTF-8 字节偏移；该操作不执行 Unicode 规范化、
大小写折叠、正则匹配或语言分词。

`文本包含` 是普通标准库函数，只读取文本和片段的共享借用，并复用 `文本查找`
判断是否返回 `可选::有值`。两个输入值都保持不变；空片段返回 `真`，未命中返回
`假`。它不登记宿主入口，也不复制 UTF-8 子串匹配规则。

`文本截取` 只读取文本的共享借用，第二个参数是从零开始的 Unicode 标量下标，
第三个参数是 Unicode 标量数量，成功时返回独立拥有的新字符串；原文本保持不变。
任一整数为负数、开始下标超过文本末尾或请求范围越过文本末尾时返回
`可选::空值`。从文本末尾开始截取零个字符返回空字符串。该操作不使用或暴露
UTF-8 字节下标，也不执行 Unicode 规范化、大小写折叠或语言分词。

`文本开头是` 和 `文本结尾是` 是普通标准库函数，只读取两个共享借用，两个输入值
都保持不变。前者检查 `文本查找` 的首个命中下标是否为零；后者先比较 Unicode
标量长度，再截取等长末尾片段并检查精确命中。空片段同时匹配开头和结尾，片段长于
文本时返回 `假`，完整相等时返回 `真`。两者不登记宿主入口，不执行 Unicode
规范化、大小写折叠、正则匹配或语言分词。

`文本去除首尾空白` 只读取共享借用，并按 Unicode `White_Space` 属性去除文本
首尾的连续空白，返回独立拥有的新字符串；原字符串不变。空字符串和全空白文本
返回空字符串，内部空白、字符顺序和所有非空白字符保持不变。该操作不执行 Unicode
规范化、本地化、正则匹配或隐式解析；`从文本` 仍然严格解析完整输入，不自动调用
该函数。

`文本转为小写` 和 `文本转为大写` 只读取共享借用，使用 Unicode 默认大小写映射
返回独立拥有的新字符串；原字符串保持不变。单个字符可以映射为多个字符，例如
`ß` 的大写结果为 `SS`。这两个操作不读取系统区域设置，不执行 Unicode 规范化或
大小写折叠。

程序参数不包含原生可执行文件路径。通过 CLI 运行时，输入路径、可选入口函数名
和第一个 `--` 分隔符也不属于程序参数；分隔符后的有效 UTF-8 值原样传入，空
字符串也会保留。直接执行 artifact 时跳过原生可执行文件路径后遵循相同规则；
无法表示为有效 UTF-8 的宿主参数在进入玄言入口前稳定失败。
`获取必需程序参数` 是普通标准库函数，只把 `获取程序参数` 的有值结果映射为成功，
把空值映射为调用者提供的错误文本；它不解析参数、不提供默认值，也不读取标志或
环境变量。`读取文本输入` 只把同一可选参数解释为文本文件路径，参数缺失时改读
标准输入；它同样不解析标志或其他参数。`列表<T>` 是普通 ADT，只有这些标准库接口提供其运行时操作；`遍历` 按
`可遍历<T>` 协议逐项取出并消费列表。

## 6. 表达式与运算符

由高到低的优先级为：

1. 调用 `()`、字段和方法 `.`、限定名称 `::`、错误传播 `?`
2. 一元 `-`、`非`、解引用 `*`
3. `*`、`/`、`%`
4. `+`、`-`
5. `<`、`<=`、`>`、`>=`
6. `==`、`!=`
7. `且`
8. `或`

`且` 和 `或` 短路求值。比较运算不链式结合。赋值不是表达式。

原始数值运算要求两侧类型一致，不执行隐式数值提升。字符串的 `==` 和 `!=` 只读取
两侧内容，不转移局部绑定所有权，比较后仍可继续使用原值。ADT 的相等和比较由静态协议
实现提供。

## 7. 结构体与枚举

### 7.1 结构体

```xy
结构体 点<T> {
    公开 横: T,
    公开 纵: T,
}

令 原点 = 点<整数> { 横: 0, 纵: 0 };

令 横 = 40;
令 纵 = 2;
令 坐标 = 点<整数> { 横, 纵 };
```

- 构造时必须且只能初始化每个字段一次。
- 字段名与初始化局部绑定名相同时，可以写成 `字段`，等价于 `字段: 字段`。
  其他初始化值继续使用 `字段: 表达式`。
- 字段读取统一使用 `值.字段`；当 `值` 是一层结构体借用时，字段访问自动解引用。
- 可变局部或可变借用字段使用 `值.字段 = 表达式;` 更新；共享借用不能写入。
  嵌套字段遵守相同根可写性规则。
- 字段赋值会按字段类型覆写并释放旧值，不构成部分移动。
- 不提供结构体更新表达式。
- 不提供隐式字段复制。

### 7.2 枚举

```xy
枚举 可选<T> {
    有值(T),
    空值,
}
```

每个变体可以没有载荷或有一个载荷。构造使用 `类型::变体` 或 `类型::变体(值)`。

核心库稳定名称为：

- `可选::有值(T)` 和 `可选::空值`
- `结果::成功(T)` 和 `结果::失败(E)`

编译器通过 LangItem 身份识别 `结果` 的两个变体，不通过名称字符串猜测。

## 8. 泛型与静态协议

泛型参数定义在名称之后：

```xy
函数 恒等<T>(值: T) -> T {
    值
}

结构体 盒子<T> {
    公开 值: T,
}
```

约束使用冒号和 `+`：

```xy
函数 相同<T: 相等 + 复制>(左: 借用<T>, 右: 借用<T>) -> 布尔 {
    左.相等(右)
}
```

调用点的类型实参由参数、接收者和期望返回类型推断。v0.1 不提供显式函数类型实参语法。

协议只声明方法：

```xy
协议 到整数 {
    函数 到整数(借用 自身) -> 整数;
}
```

实现使用：

```xy
实现 到整数 为 计数器 {
    函数 到整数(借用 自身) -> 整数 {
        自身.值
    }
}
```

- 协议方法使用 `自身`、`借用 自身` 或 `可变借用 自身` 声明移动、共享借用或可变借用接收者。
- Parser 将接收者简写归一为首个名为 `自身` 的现有参数；实现方法签名中的同名类型由实现目标类型替换。
- 方法调用使用 `值.方法(参数)`。调用根据 `自身` 参数类型移动接收者，或自动创建共享借用、可变借用。
- 不带 `自身` 参数的实现函数是关联函数，调用使用 `类型::函数(参数)`。
- 泛型在编译期单态化。
- 协议实现必须唯一且静态确定。

协议关联类型、默认方法、特化、动态派发和运行时虚表延期。

## 9. 控制流

### 9.1 条件

```xy
令 结果值 = 如果 条件 {
    42
} 否则 {
    0
};
```

条件必须是 `布尔`。有结果的 `如果` 必须有 `否则`，且各分支结果类型一致。

### 9.2 循环

```xy
当 条件 {
    语句;
}

循环 {
    如果 完成 {
        跳出;
    }
    继续;
}

遍历 元素 在 (可迭代值) {
    语句;
}
```

`跳出` 和 `继续` 只作用于最内层循环。`跳出` 不携带值。循环表达式的类型为 `空`。

核心库前导环境声明普通泛型协议：

```xy
协议 可遍历<T> {
    函数 下一个(可变借用 自身) -> 可选<T>;
}
```

`遍历` 把右侧值移动到隐藏的可变局部中，反复调用已由 Resolver 解析的
`可遍历<T>::下一个`，直到得到 `可选::空值`。该协议按 `DefId` 解析，不通过
名称字符串识别，也不要求编译器认识具体集合类型。来源是单个标识符时使用括号，
以区别紧随其后的循环体和结构体字面量；格式器保留这组消歧括号。

## 10. 模式匹配

```xy
匹配 值 {
    可选::有值(内容) => 内容,
    可选::空值 => 0,
}
```

允许的模式：

- 枚举变体及其单个载荷模式
- 列出全部字段的结构体模式
- 布尔、整数、字符和字符串字面量
- 新绑定
- `_`

每个分支使用 `模式 => 表达式,`。枚举匹配必须穷尽；其他类型可以使用 `_` 补足。

v0.1 不提供匹配守卫、范围模式、or-pattern、列表头尾解构、字段省略和产生部分移动的嵌套资源模式。
枚举载荷可以继续使用完整结构体模式或其他已支持的完整子模式；这不会开放枚举值
中普通字段的单独移动。

完整结构体模式匹配成功后会整体消费被匹配值，并把全部字段初始化为分支内局部值。
资源字段可以从对应模式绑定中移动一次；未绑定名称的字段仍按其类型正常清理。
这不开放普通表达式从结构体中单独移出资源字段。

结构体模式必须列出全部字段。当字段名和绑定名相同时，可以省略冒号及重复的绑定名，
写成 `字段`，等价于 `字段: 字段`；非绑定或不同名称的子模式仍使用显式的
`字段: 模式`。

## 11. 闭包

闭包使用匿名函数语法：

```xy
令 加法 = 函数(值: 整数) -> 整数 {
    基数 + 值
};
```

- 参数和返回类型必须显式声明。
- 使用的外部局部值自动按移动捕获。
- 闭包不能按共享借用或可变借用捕获。
- 需要保留原值时，先显式调用 `复制()`，再让闭包移动副本。
- 闭包不能逃逸任何借用。

## 12. 移动、复制与借用

### 12.1 移动与复制

原始数值、`布尔`、`字符` 和借用值具有隐式复制语义。其他值默认移动。

```xy
令 后继 = 原值;
```

如果 `原值` 不是可复制值，上述绑定后再次使用 `原值` 产生 `OWN001`。

实现核心 `复制` 协议的类型可以显式复制：

```xy
令 副本 = 原值.复制();
```

字段读取遵守字段本身的移动或复制语义，不存在隐式深复制。v0.1 禁止部分移动，因此从拥有资源字段的结构体中移出单个字段是错误。

### 12.2 借用

创建共享借用和可变借用：

```xy
令 读 = 借用(值);
令 写 = 可变借用(可变值);
```

- 同一值可以同时存在多个共享借用。
- 存在共享借用时不能创建可变借用、移动或写入原值。
- 存在可变借用时不能创建其他借用、读取、移动或写入原值。
- `*借用值` 读取被借用值。
- `*可变借用值 = 新值;` 写入被借用值。
- `借用值.字段` 自动解一层借用读取结构体字段；`可变借用值.字段 = 新值;`
  写入字段，共享借用不允许写入。
- 借用区域由编译器推断，到最后一次使用结束，且不能跨出当前函数。
- 借用不能存入 ADT、从函数返回或被闭包捕获。

普通函数或关联函数调用中，如果参数期望 `借用<T>`，类型为 `T` 的已初始化直接
局部绑定或产生拥有值的右值表达式可以直接作为实参。直接局部绑定记录为非消费
共享借用；字面量、调用结果、构造结果等右值先物化为只覆盖该次调用的临时值，再
创建共享借用。如果参数期望 `可变借用<T>`，实参仍必须是使用 `变量` 声明的直接
局部绑定。调用结束后借用和右值临时值按顺序释放，直接局部绑定仍归调用方所有。
已经具有匹配借用类型的实参按原类型传递。

```xy
函数 查看(值: 借用<整数>) -> 整数 {
    *值
}

函数 增加(值: 可变借用<整数>) -> 空 {
    *值 = *值 + 1;
}

变量 数值 = 41;
令 原值 = 查看(数值);
增加(数值);
```

调用期自动共享借用适用于直接局部绑定，以及字面量、调用结果、构造结果和其他
产生拥有值的右值表达式。字段投影和显式解引用仍不会自动创建借用，需要时先绑定
为局部值；调用期自动可变借用也只适用于可变直接局部绑定。显式 `借用(...)` 与
`可变借用(...)` 用于从局部绑定创建需要跨表达式保存的借用值，以及表达显式解
引用或借用冲突。

### 12.3 释放

需要清理的完整值在离开作用域时自动释放。局部值按创建顺序逆序释放；仍由当前函数拥有的参数在局部值之后按参数声明逆序释放。已移动的旧位置不再释放。

用户类型通过核心 `释放` 协议提供清理：

```xy
协议 释放 {
    函数 释放(自身) -> 空;
}
```

正常块退出以及 `返回`、`跳出`、`继续` 路径都必须执行相同所有权状态要求的清理。每个完整值最多释放一次。

## 13. 可恢复错误

玄言不提供异常。可恢复错误使用 `结果<T, E>`。

```xy
函数 读取() -> 结果<整数, 字符串> {
    结果::成功(42)
}

函数 使用() -> 结果<整数, 字符串> {
    令 值 = 读取()?;
    结果::成功(值 + 1)
}
```

`?` 只接受核心 LangItem 登记的 `结果<T, E>`：

- `结果::成功(值)?` 产生载荷值。
- `结果::失败(错误)?` 立即从当前函数返回同一失败值。
- 当前函数必须返回 `结果<U, E>`，错误类型必须完全相同。
- v0.1 不执行隐式错误转换。

`可选<T>` 不支持 `?`。不可恢复错误使用统一运行时终止路径。

## 14. 规范诊断

诊断正文使用中文，并包含稳定代码、主源码范围和必要的关联范围。首批规范程序冻结以下代码：

| 代码 | 含义 |
| --- | --- |
| `SYN001` | 使用已删除的绑定语法 |
| `SYN002` | 局部绑定缺少初始化表达式 |
| `RES001` | 名称无法解析 |
| `TYP001` | 表达式类型与要求类型不一致 |
| `TYP002` | 枚举匹配不穷尽 |
| `OWN001` | 值移动后再次使用 |
| `OWN002` | 共享借用与可变借用冲突 |

解析器只报告语法事实；Resolver 负责名称和可见性；类型与所有权阶段分别负责 `TYP*` 和 `OWN*`。后端不得重新生成这些用户诊断。

## 15. 明确延期或删除

v0.1 不包含：

- `绑定`、`可变 变量` 和未初始化局部声明
- 源码生命周期、借用字段、借用返回和借用闭包捕获
- 部分移动、结构体更新和隐式深复制
- 协议关联类型、动态协议对象、特化和高阶类型
- 匹配守卫、范围模式、or-pattern 和列表解构
- 类型别名、元组、数组、宏、反射和运行时类型信息
- 锁、其他原子算术、布尔原子、异步、用户 FFI、裸指针和 `底层扩展`
- 远程包仓库、发布语义、IDE 或 LSP 专用语法

这些项目不能通过兼容开关、后端特殊分支或未记录语法重新进入语言核心。
